# Первое включение SmartSense

Это пошаговое руководство для новичков. Мы проведём вас от распаковки до первого сигнала.

## Что понадобится

- Контроллер SmartSense
- Кабель USB-C
- Компьютер с установленным Python 3.10+

## Шаг 1. Распаковка

Достаньте контроллер из антистатического пакета. Проверьте комплектность:

- [x] Плата SmartSense
- [x] USB-C кабель
- [x] Антенна Wi-Fi

## Шаг 2. Подключение питания

Подключите кабель к порту USB-C на плате и к компьютеру.

!!! warning "Внимание"
    Используйте только кабель из комплекта. Сторонние кабели могут не поддерживать передачу данных.

## Шаг 3. Проверка подключения

Откройте терминал и выполните:

```bash
python -c "import serial; print(serial.tools.list_ports.comports())"
