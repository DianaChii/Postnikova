# ADR-001: Файловое хранилище вместо SQLite

## Статус

Принято

## Контекст

Нужно хранить документы для системы DocHub. Варианты:
- Файловая система (Markdown файлы)
- SQLite база данных
- Git-репозиторий

## Решение

Выбрано файловое хранилище: документы лежат в папке `docs/` как обычные `.md` файлы.

## Альтернативы

### SQLite

**Плюсы:**
- Быстрый поиск
- Транзакции
- Структурированные данные

**Минусы:**
- Нужны миграции
- Сложнее версионировать
- Двойное хранение (файл + БД)

### Git

**Плюсы:**
- История изменений из коробки
- Ветвление
- Code review

**Минусы:**
- Сложнее для новичков
- Нужен git на сервере

## Последствия

**Положительные:**
- Простота: документ = файл
- Легко редактировать в любом редакторе
- Работает с git без дополнительных настроек
- Мгновенное обновление (добавил файл → появился на сайте)

**Отрицательные:**
- Медленнее поиск по большому объёму
- Нет транзакций
- Нужно следить за целостностью вручную
