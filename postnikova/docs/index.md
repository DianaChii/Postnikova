# Документация IoT-устройства SmartSense

Добро пожаловать в документацию IoT-контроллера SmartSense.

## Обзор системы

SmartSense — это IoT-контроллер для сбора телеметрии и управления устройствами через Wi-Fi.

## Глоссарий

| Термин | Определение |
|--------|-------------|
| MQTT | Протокол обмена сообщениями для IoT |
| Телеметрия | Данные с датчиков (температура, влажность) |
| GPIO | Цифровые входы/выходы общего назначения |
| ШИМ | Широтно-импульсная модуляция для управления мощностью |
| Топик | Канал в MQTT, на который подписываются клиенты |
| Брокер | Сервер, пересылающий MQTT сообщения |
| Прошивка | Встроенное ПО контроллера |
| Watchdog | Аппаратный таймер для перезагрузки при зависании |
